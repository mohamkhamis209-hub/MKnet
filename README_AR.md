## 🚀 نظرة عامة

مشروع **MKnet Network Manager** هو منصة برمجية متكاملة واحترافية لإدارة الشبكات المحلية وتقسيم باقة الإنترنت بعدالة بين المستخدمين. يتيح النظام تحديد حصة شهرية أو يومية لكل شخص (جيجابايت محددة أو نسبة متساوية من المتبقي)، تتشاركها جميع أجهزته (هواتف، لابتوبات، شاشات ذكية). وعند انتهاء حصة مستخدم معين، يتم إيقاف الإنترنت عن أجهزته هو فقط دون التأثير على باقي أفراد الشبكة.

يقدم MKnet مستويين للعمل:
1. **وضع النشر السريع والتجربة (GitHub Pages / Static Mode)**: يعمل مباشرة عبر GitHub Pages أو أي خادم ويب ثابت بدون أي أوامر بناء (Build) أو Node.js، مع واجهة استعراضية وتجريبية (Demo Mode) وتطبيق PWA قابل للتثبيت.
2. **وضع البوابة الفعلي (Real Gateway Mode)**: خادم Python متكامل يعمل على جهاز الراوتر أو بوابة الشبكة، يربط واجهات REST وWebSocket مع حزم `nftables` في النواة لتحديد السرعات، وفلترة DNS، وحظر الأجهزة، وبث البيانات الحية.

## 🌟 أبرز مميزات MKnet

- **توزيع الحصص الشهرية واليومية**: إمكانية ضبط باقة عامة وتحديد نصيب كل فرد مع عدادات دقيقة.
- **تحديد السرعات والتحكم في البنج (QoS)**: تقنيات متقدمة تمنع ارتفاع زمن الاستجابة (Ping) في الألعاب أثناء التحميلات الثقيلة.
- **التحكم الفوري بالأجهزة**: حظر، فصل، إلغاء حظر، أو تحديد سرعة أي جهاز بضغطة زر واحدة.
- **حجب الإعلانات والمواقع الضارة (DNS Filtering)**: حماية متكاملة باستخدام قوائم عالمية لحجب الإعلانات والتتبع والمحتوى غير المرغوب فيه.
- **مشاركة الملفات المباشرة (Local Share)**: نقل وتبادل الملفات بين الأجهزة المتصلة بالشبكة بسرعة فائقة دون الحاجة للإنترنت.
- **تطبيق PWA قابل للتثبيت**: تثبيت التطبيق على الهواتف وأجهزة الكمبيوتر مع وضع العمل بدون إنترنت (Offline Mode).
- **واجهة عصرية باللغتين العربية والإنجليزية**: دعم كامل للاتجاهين (RTL/LTR)، والوضع الداكن والفاتح، والتوافق مع جميع مقاسات الشاشات.

## 🌐 النشر على GitHub Pages

المشروع مهيأ تمامًا للنشر المباشر على **GitHub Pages** داخل أي مستودع، ويعمل بدون أخطاء 404 أو مشاكل في المسارات.

### خطوات النشر:
1. ارفع المشروع إلى مستودعك على GitHub:
   ```bash
   git init
   git add .
   git commit -m "إطلاق مشروع MKnet Network Manager"
   git branch -M main
   git remote add origin https://github.com/USERNAME/REPOSITORY.git
   git push -u origin main
   ```
2. ادخل إلى إعدادات المستودع **Settings** في GitHub.
3. توجه إلى قسم **Pages** من القائمة الجانبية.
4. تحت خانة **Build and deployment**، اختر الفرع `main` والمجلد `/ (root)`.
5. اضغط على **Save**.
6. خلال دقائق، سيصبح موقعك متاحًا على الرابط:
   `https://USERNAME.github.io/REPOSITORY/`

### التعامل مع وضع GitHub Pages:
- يعرض الموقع تلقائيًا **وضع العرض التجريبي (Demo Mode)** عند عدم وجود خادم بوابة متصل.
- تظهر لافتة توضيحية بارزة تؤكد للمستخدم أن البيانات استعراضية ولا تنفذ عمليات حقيقية على الراوتر.
- يمكن للمستخدم في أي وقت الضغط على أيقونة **إعدادات الخادم** لإدخال عنوان بوابة MKnet الحقيقية (مثل `http://192.168.1.1:8080`) للربط المباشر.

## 📱 تثبيت تطبيق PWA على الأجهزة المختلفة

تطبيق MKnet مصمم كـ **Progressive Web App** متكامل:

### أجهزة Android:
1. افتح رابط الموقع في متصفح Chrome.
2. اضغط على زر **«تثبيت التطبيق»** الظاهر في الشريط العلوي، أو من قائمة المتصفح (⋮) اختر **«تثبيت التطبيق»** أو **«إضافة إلى الشاشة الرئيسية»**.
3. سيتم تثبيت MKnet كتطبيق مستقل يعمل بكامل الشاشة وله أيقونة خاصة على جهازك.

### أجهزة Windows و Mac والكمبيوتر:
1. افتح رابط الموقع في Google Chrome أو Microsoft Edge أو Brave.
2. اضغط على زر **«تثبيت التطبيق»** في الواجهة أو أيقونة التثبيت في شريط العنوان أعلى المتصفح.
3. سيفتح التطبيق في نافذة مستقلة قابلة للتثبيت في شريط المهام (Taskbar).

### أجهزة iPhone و iPad (iOS):
1. افتح الرابط في متصفح **Safari**.
2. اضغط على زر **المشاركة** (الأيقونة ذات السهم الصاعد في الأسفل).
3. اختر **«إضافة إلى الصفحة الرئيسية» (Add to Home Screen)** ثم اضغط **إضافة (Add)**.

## 🖥️ تشغيل خادم البوابة الفعلي (Gateway Server)

لتشغيل MKnet كبوابة حقيقية للتحكم بالإنترنت وأجهزة الراوتر، يتم تشغيله على جهاز كمبيوتر يعمل بنظام Linux (مثل Debian، Ubuntu، Kali، Raspberry Pi، أو Mini PC):

### المتطلبات:
- نظام Linux مع صلاحيات الجذر (Root) ونظام حزم `nftables`.
- Python 3.10 أو أحدث.
- تثبيت الاعتماديات:
  ```bash
  pip install -r requirements-linux.txt
  ```

### التشغيل:
```bash
python run.py
```
أو لتحديد منفذ مخصص:
```bash
python run.py --port 8080
```

سيبدأ الخادم فورًا بتقديم واجهة الويب، وتوفير اتصالات WebSocket الحية، والتحكم الفعلي بحزم الإنترنت.

## 🔒 الأمان وحماية البيانات

- **خصوصية محلية 100%**: لا يتم إرسال أي بيانات للأجهزة أو المواقع إلى أي سحابة خارجية.
- **حماية CSRF مضاعفة**: التحقق الإلزامي من ترويسات `X-MK-CSRF: 1` و `X-QM-CSRF: 1` لجميع العمليات التعديلية.
- **أمان Service Worker**: حظر تخزين أي طلبات API أو جلسات دخول أو كلمات مرور داخل Cache المتصفح.
- **دعم CORS الآمن**: إمكانية الربط بين واجهة GitHub Pages وخادم البوابة المحلي بأمان تام.
